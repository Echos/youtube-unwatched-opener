# YouTube未視聴動画オープナー ブラウザ拡張機能

YouTube登録チャンネルページで未視聴動画を効率的に別タブで開くブラウザ拡張機能です。動画のビジュアルハイライト、プレイリスト管理、ショート動画の通常動画化など多彩な機能を提供します。

**対応ブラウザ**: Google Chrome、Firefox（109+）

## 主な機能

### 未視聴動画オープナー
- **ショートカットキー（デフォルト：Ctrl+Enter）** で未視聴動画を別タブで開く
- **開く動画数を設定可能**（デフォルト：5本、1-50の範囲）
- **古い動画から優先**して開く
- **重複排除**で同じ動画が複数開かれることを防止

### 動画ハイライト機能
- **未視聴動画**: 青色のボーダーと「未視聴」ラベル
- **ライブ中**: 赤色のボーダーと「🔴 LIVE」ラベル（パルスアニメーション付き）
- **視聴済み**: 完全非表示（画面から除外）
- **公開予定**: 完全非表示（画面から除外）
- **プレミア公開**: オレンジ色のボーダーと「プレミア公開」ラベル
- **ハイライト切り替え**：Ctrl+Shift+Hで機能のON/OFF

### 動画プレイヤー機能
- **後で見る切り替え**：「r」キーで後で見るプレイリストに追加/削除
- **プレイリストパネル**：右サイドバーにYouTubeネイティブのプレイリストダイアログを表示
- **ショート動画変換**：ショート動画を自動的に通常の動画プレイヤーで再生
- **画質自動優先設定**：動画再生時に1440p（あれば）／1080pを自動的に優先選択

### 設定機能
- **ポップアップ設定画面**で各種設定を変更可能（ダークテーマUI）
- **ショートカットキー**のカスタマイズ
- **開く動画数**の設定（1-50本）
- **各機能の個別ON/OFF切り替え**（トグルスイッチ）
- **デバッグモード**（開発者向け）：コンソールに詳細なログ出力
- **設定の永続化**（Chrome同期ストレージ使用）

## インストール方法

### 1. ソースコードをダウンロード
```bash
git clone https://github.com/your-username/youtube-unwatched-opener.git
cd youtube-unwatched-opener
```

### 2-A. Chromeにインストール
1. Chromeブラウザで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. ダウンロードした `youtube-unwatched-opener` フォルダを選択

### 2-B. Firefoxにインストール
1. Firefoxブラウザで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」をクリック
3. ダウンロードした `youtube-unwatched-opener` フォルダ内の `manifest.json` を選択
4. アドオンが読み込まれたことを確認

**注意**: Firefoxでは一時的なアドオンとして読み込まれるため、ブラウザを再起動すると削除されます。

## 使用方法

### 基本操作
1. **YouTube登録チャンネルページ**（`https://www.youtube.com/feed/subscriptions`）にアクセス
2. **Ctrl+Enter**を押すと未視聴動画が別タブで開かれます
3. **Ctrl+Shift+H**でハイライト機能のON/OFFを切り替え

### 動画プレイヤーでの操作
1. **動画ページ**で**「r」キー**を押すと後で見るプレイリストに追加/削除
2. **右サイドバーのプレイリストパネル**でプレイリスト管理が可能
3. **ショート動画**は自動的に通常の動画プレイヤーで再生

### 設定変更
拡張機能アイコンをクリックして設定画面を開きます。設定は変更と同時に自動保存されます。

### 動画の識別・分類ロジック
- **未視聴動画**: YouTube DOM要素内の未視聴インジケーター（青い点）を検出
- **視聴済み動画**: プログレスバーの有無と進捗状況をチェックして完全非表示
- **公開予定動画**: バッジやテキストで識別して完全非表示
- **ショート動画**: 7つの検出方法による徹底的な排除
- **ライブ・プレミア**: 特定のバッジやスタイルで識別してハイライト表示

## トラブルシューティング

### 拡張機能が動作しない場合
1. YouTube登録チャンネルページ（/feed/subscriptions）にいることを確認
2. 拡張機能が有効になっているかポップアップで確認
3. ページを再読み込みしてから再試行

### 未視聴動画が正しく識別されない場合
- YouTubeの構造変更により一時的に動作しない可能性があります
- ページを再読み込みしてから再試行してください

### 設定が保存されない場合
- Chromeの同期設定が有効になっているか確認
- 拡張機能の権限が正しく設定されているか確認

### プレイリスト機能の問題が発生した場合
- 動画タイトルに「保存」が含まれる場合の誤動作: 修正済み（v1.5.0）
- バックグラウンドタブでの動作: タブがアクティブになった際に自動的に再実行
